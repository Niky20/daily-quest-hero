# Daily Quest Hero

Build a gamified daily planner application that transforms personal productivity into an engaging, interactive game where users can add, manage, and track their daily tasks. The core mechanic should feature a visual streak system that tracks consecutive days of completed activities, prominently displaying the user's current streak and highest record to encourage daily habit building. To maximize engagement, implement an interactive reward loop where simply checking off a task isn't enough; instead, upon completing a task, a dynamic "Claim Reward" button must appear, requiring users to manually click it to trigger satisfying visual confetti animations and earn in-app rewards like virtual coins or experience points. The overall user interface should be vibrant, intuitive, and mobile-responsive, blending standard to-do list functionality with RPG-like elements, progress bars, and a celebratory aesthetic that makes organizing daily life feel highly rewarding and fun. the app will have leveling up system and the is consequence if streak is broken it will lower the experience poin that already have accumulated
